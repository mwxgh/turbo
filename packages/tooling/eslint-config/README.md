# `@repo/eslint-config`

Shared flat configs, each exported as `config`:

| Import                      | For                                  |
| --------------------------- | ------------------------------------ |
| `@repo/eslint-config/base`  | TypeScript libraries                 |
| `@repo/eslint-config/nest`  | NestJS apps (Node globals)           |
| `@repo/eslint-config/next`  | Next.js apps (browser + React hooks) |
| `@repo/eslint-config/react` | React libraries (`@repo/ui`)         |
